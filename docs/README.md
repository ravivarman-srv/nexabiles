# Nexabilis Docs

A comprehensive CRM and Voice AI platform built for scaling businesses.
These docs walk you through setting up and configuring the platform.

## Reading order

**Setup**

1. **[Getting started](./getting-started.md)** - Account creation and quick setup.
2. **[WhatsApp setup](./whatsapp-setup.md)** - Create a Meta app, connect a phone number, wire the webhook.
3. **[Environment variables](./environment-variables.md)** - The full reference.

**Deploy**

4. **[Deploy on Hostinger](./deployment-hostinger.md)** - Managed Node.js Hosting walkthrough (if self-hosting the application).
5. **[Automations cron](./automations-and-cron.md)** - Schedule the pending executions drain so waits and delays fire.

**Reference**

6. **[Architecture](./architecture.md)** - Stack, folder layout, request lifecycle.
7. **[Troubleshooting](./troubleshooting.md)** - The usual suspects.

## What you will need before starting

- A [Meta for Developers](https://developers.facebook.com) account with a WhatsApp Business app.
- A WhatsApp phone number that is **not** already tied to the regular WhatsApp or WhatsApp Business mobile apps.
